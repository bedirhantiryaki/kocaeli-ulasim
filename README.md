## 📋 Proje Hakkında

Bu proje, React Native ve Expo kullanılarak geliştirilmiş modern bir mobil uygulamadır. Kullanıcı dostu arayüzü ve güçlü özellikleriyle dikkat çeken bu uygulama, çoklu platform desteği sunmaktadır.

## ✨ Öne Çıkan Özellikler

### 🗺️ Harita ve Konum Özellikleri

- 📍 Gerçek zamanlı konum takibi
- 🎯 Özel konum işaretçileri
- 🛣️ Rota planlama ve navigasyon
- 🔍 Detaylı harita görünümü

### 🎨 Kullanıcı Arayüzü

- 💫 Modern ve şık tasarım
- 🌙 Karanlık/Aydınlık tema desteği
- 🎭 Özelleştirilebilir arayüz
- 📱 Responsive tasarım

### 🔧 Teknik Özellikler

- ⚡ Yüksek performans
- 🔒 Güvenli veri yönetimi
- 📊 Gerçek zamanlı veri senkronizasyonu
- 🔄 Otomatik güncelleme sistemi

## 🚀 Başlangıç

### Gereksinimler

- Node.js (v14 veya üzeri)
- npm veya yarn
- Expo CLI
- iOS Simulator (macOS için) veya Android Emulator

### Kurulum Adımları

1. Projeyi klonlayın:

```bash
git clone [repo-url]
cd proje
```

2. Bağımlılıkları yükleyin:

```bash
npm install
# veya
yarn install
```

3. Geliştirme sunucusunu başlatın:

```bash
npm start
# veya
yarn start
```

4. Uygulamayı çalıştırın:

- iOS için: `npm run ios` veya `yarn ios`
- Android için: `npm run android` veya `yarn android`
- Web için: `npm run web` veya `yarn web`

## 🛠️ Geliştirme

### Kod Yapısı

```
proje/
├── src/
│   ├── components/     # Yeniden kullanılabilir bileşenler
│   ├── screens/        # Ekran bileşenleri
│   ├── navigation/     # Navigasyon yapılandırması
│   ├── services/       # API ve servis katmanı
│   ├── utils/          # Yardımcı fonksiyonlar
│   └── types/          # TypeScript tip tanımlamaları
├── assets/            # Görseller ve medya dosyaları
└── ...
```

2. Yeni bir branch oluşturun:

```bash

```

3. Değişikliklerinizi commit edin:

```bash
git commit -am 'Yeni özellik: [açıklama]'
```

4. Branch'inizi push edin:

```bash

```

5. Pull Request oluşturun
